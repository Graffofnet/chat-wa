# chat-wa
Как это работает
Клиент (автор)              Сервер                     Клиент (получатель)
     │                        │                                │
     │── delete_message ─────▶│                                │
     │   { messageId }        │ 1. ищет сообщение в Map      │
     │                        │ 2. сверяет ownerId с сокетом │
     │                        │── message_deleted ────────────▶│
     │◀── message_deleted ────│                                │
     │                        │                                │
  🗑 исчезает              удалено                          🗑 исчезает

  ⚠️ Ограничение
Пока сообщения хранятся в Map в оперативной памяти сервера. После перезапуска сервера:
история чата исчезнет;
удалить старые сообщения не получится (сервер их «не помнит»).
Для продакшена добавьте базу данных (например, SQLite/MongoDB): храните { messageId, ownerId, audioUrl, createdAt }, а аудио-файлы сохраняйте на диск. Тогда удаление будет работать всегда.
