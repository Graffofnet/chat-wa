# chat-wa — голосовой чат в стиле WhatsApp (Node.js + Socket.IO)

## Как это работает
Клиент (автор)              Сервер                     Клиент (получатель)
     |                        |                                |
     |-- delete_message ----->|                                |
     |   { messageId }        | 1. ищет сообщение в Map      |
     |                        | 2. сверяет ownerId с сокетом  |
     |                        |-- message_deleted ----------->|
     |<-- message_deleted ----|                                |
     |                        |                                |
  (исчезает)              удалено                          (исчезает)

## Установка на виртуальный хостинг (cPanel / Setup Node.js App)

1. Загрузите файлы проекта в папку вне public_html (например, ~/wa-chat).
   Нужны: server.js, app.js, package.json, index.html, logo.png.
   Папку node_modules загружать не нужно — установится на шаге 3.
2. Создайте приложение Node.js в панели хостинга:
   - Application root: путь к папке ~/wa-chat
   - Application URL: ваш домен/поддомен
   - Startup file: app.js
   - Node.js version: 14 или новее
3. Установите зависимости в SSH-терминале:
   cd ~/wa-chat && npm install --production
4. Перезапустите приложение в панели и откройте указанный Application URL.

Сервер сам отдаёт страницу index.html, картинку logo.png и клиентскую
библиотеку Socket.IO по адресу /socket.io/socket.io.js — CDN не требуется.
Порт сервер берёт из переменной окружения PORT, которую задаёт панель
хостинга (локально по умолчанию — 3000).

### Запуск локально
    npm install
    npm start          # http://localhost:3000

### Если хостинг проксирует трафик через Apache
В проекте есть заготовка .htaccess — раскомментируйте правила Rewrite
и укажите порт, выданный приложению (обычно cPanel сам настраивает
проксирование, трогать .htaccess не нужно).

## Ограничения
- Сообщения хранятся в Map в оперативной памяти сервера. После перезапуска:
  история чата исчезнет; удалить старые сообщения не получится.
  Для продакшена добавьте БД (SQLite/MongoDB): храните
  { messageId, ownerId, audioUrl, createdAt }, а аудио сохраняйте на диск.
- На дешёвых виртуальных хостингах WebSockets могут блокироваться.
  Socket.IO автоматически откатится на long-polling — настройки не нужны.
- Голосовые сообщения пересылаются как base64; размер одного сообщения
  ограничен maxHttpBufferSize (100 МБ). При необходимости уменьшите.

## Найдены и исправлены ошибки
1. server.js раздавал статику из несуществующей папки public/ и файла
   public/chat.html -> сайт отдавал 404. Теперь статика берётся из корня
   проекта, главная страница — index.html.
2. Порт был жёстко зашит (3000) -> на cPanel приложение не запускалось.
   Теперь читается из process.env.PORT.
3. В package.json не было main и скрипта start; добавлен app.js как
   startup-файл для панелей хостинга.
4. Подключён необязательный интеграционный слой detect-json (паттерн
   cPanel Node.js Selector) с graceful-fallback для обычного запуска.
5. В клиенте убран автозапрос микрофона при загрузке страницы (браузеры
   его блокируют без действия пользователя); разрешение запрашивается по
   первому нажатию на кнопку записи.
